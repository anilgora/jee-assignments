# Hindi terms and phrasing for JEE maths questions

Write Hindi in Devanagari Unicode. Keep all maths in `$...$` exactly as in English. Put English in brackets only when a Hindi term is ambiguous, for example `नीचे की ओर अवतल (concave downward)`.

## Stock sentences
| English | Hindi |
|---|---|
| Let ... | माना कि ... |
| Then the value of ... is | तब ... का मान है |
| is equal to | बराबर है |
| is ______ | ______ है |
| If ..., then | यदि ... है, तो |
| Which of the following statement(s) is(are) correct? | निम्न में से कौन-सा/से कथन सही है/हैं? |
| defined by | द्वारा परिभाषित |
| Only one option is correct. | केवल एक विकल्प सही है। |
| One or more options is(are) correct. | एक या अधिक विकल्प सही हो सकते हैं। |
| The answer is a non-negative integer. | उत्तर एक अऋणात्मक पूर्णांक है। |
